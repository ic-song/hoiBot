# 레거시 인형뽑기 배포 안내

기획: https://app.notion.com/p/2cf393bdd7aa83f4b1a301accd4d28eb

Codex의 운영반영은 원격 `feature/prod` 소스 반영까지다. 아래 파일 업로드와 컴파일은 운영자가 기존 절차로 진행한다.

## 최초 설치

1. 기존 회원·펫·운영 데이터의 백업을 보관한다.
2. 신규 고정 목록 `data/dollCatalog.json`을 `/sdcard/호이랜드/dollCatalog.json`에 배치한다.
3. `data/dollIndex.json`, `data/dollPending.json`, `data/dollRecords_0.json`부터 `data/dollRecords_15.json`까지를 같은 경로에 최초 한 번 배치한다. 이미 존재하는 운영 파일은 빈 초기 파일로 덮어쓰지 않는다.
4. 검증된 같은 버전의 `main.js`와 `Info.js`를 기존 절차로 반영·컴파일한다.
5. DEV에서는 기존 `dev/데이터백업` 절차로 전용 사용자 파일을 복사한다. 고정 목록은 변경하지 않는 공통 파일로 읽는다.

최초 설치에는 고정 목록 1개와 초기 사용자/복구 파일 18개가 필요하다. 일부만 배치하면 누락 오류를 그대로 발생시키며 빈 데이터를 대신 만들지 않는다.

## 기록 보관

- 도감은 이름 기준의 16개 전용 파일에 보관한다. 이름 변경에 따른 기록 이전은 이번 범위에 포함하지 않는다.
- 회원 파일에는 도감 원본을 넣지 않는다. 펫 파일에는 캐슬·레이드 계산에 사용하는 누적 종합매력 요약만 저장한다.
- `dollIndex.json`은 순위용 대표 기록, `dollPending.json`은 완료되지 않은 뽑기의 이전 파일 원문이다.
- 완료되지 않은 뽑기는 다음 MAIN 요청에서 이전 원문으로 복구한다. 복구 기록이 남아 있으면 Info는 부분 반영 상태를 출력하지 않는다.
- 이후 소스 갱신 때 사용자·복구 파일을 초기 파일로 교체하지 않는다. 고정 목록 수정이 필요할 때도 기존 ID를 임의로 바꾸지 않는다.

## 운영 확인

- `/인형가이드`의 비용·확률·매력 설명을 확인한다.
- DEV에서 뽑기·도감·순위와 마지막 이용권 안내를 확인한다.
- 150종 상세 도감의 전체보기와 긴 출력이 카카오톡에서 정상 표시되는지 확인한다.
- 프리미엄 이용권은 기존 구독 보상의 날짜별 중복 방지를 따른다. 이미 오늘의 구독 보상을 받은 계정은 같은 날짜 재실행으로 이용권을 추가 지급받지 않는다.
