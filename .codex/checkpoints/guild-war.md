- 기존 영지전의 호월킹덤 수동/자동 공격·랜덤 해제·초기화를 제외하고 다른 영지는 유지한다. 호월킹덤 점령 길드와 영주의 현재 가입 길드를 분리 표시한다.

## 검증

- 실제 신규 함수를 추출한 합성 Node VM: 39,563 assertions 통과. 이 중 다수는 10,000개 균등 표본의 64% 방어 경계 확인이다. 별개의 39,563개 시나리오라는 뜻이 아니다.
- 정상 선포/차단/동시 방어/임시 재배열/탈퇴·해산/정찰권·공격권/자정 리셋·환급 상한/수신별 UI/기록 개인정보/구형 아이템/DEV/손상 저널·필수 사본·타 콘텐츠 게시 충돌 검증.
- Rhino1.7.15 -Xmx128m: 실제 writeVerifiedJsonFile·스트림 직렬화·복사/해시·백업 교체와 신규 저널을 사용해 68 checks 통과. 14개 대용량 합성 원본, 회원/길드 저장 후 중단, 완료 표식 직전 실패, 정확한 원본·백업 복구, 정상 완료 재실행 방지 포함.
- 별도 Java 프로세스 prepare → 종료 → recover로 재시작 복구 16 checks 통과.
- 전체 main.js/Info.js Rhino -Xmx384m 컴파일, node --check, git diff --check, UTF-8 replacement 문자 없음, 기존 7인자 callback 유지 확인.
- 실제 Android/MessengerBot API 전달·스케줄 지연·실제 채팅방 출력은 로컬에서 실측하지 않았다. 외부 알림 성공 직후 중단 시 전송 확인 한계는 정산의 중복 방지와 구분한다.
- 본 길드전쟁 검증의 임시 스크립트·합성 파일 28개 및 빈 fixture 디렉터리는 삭제했다. 이전 추리소설 작업의 임시 자료·초안은 보존했다. 영구 테스트 파일은 추가하지 않았다.
