## 확인한 범위와 결과

실행 JS 4개(main.js, Info.js, notice.js, data/miniGameBot.js)의 모든 타이머 선언·호출, Java Thread/Timer·sleep 및 명령 진입 자동복구·프리미엄 만료 경로를 추적했다. 타이머 선언은 Main 17곳 + notice 1곳이며 공용 interval 래퍼도 포함한다. 단순 선언 개수는 실제 실행 빈도를 뜻하지 않는다.

- 펫탐험: 자동 정산 기본 60분. 회원·펫·스킬·길드·홈·탐험 자료를 읽어 전체 참여자를 정산하고 저장. 출발 공지 후 Thread.sleep(10000)을 공용 데이터 잠금 안에서 수행한다. shouldAnnouncePetExploreStart는 일반 탐험에서 항상 true, 달토끼 이벤트에서 참여자 > 0일 때 true. 확실한 10초 잠금 점유 원인이며 그동안 일반 명령 tryLock 실패로 무응답 가능. 현 작업에서는 출발 절차·기록 일관성을 보존하기 위해 변경하지 않았다.
- 기존 길드영지전: 시작 유예 20초/5초, 수동 턴 10초·자동 공격 1초. 유효 턴마다 회원·펫·스킬·길드, 자동 공격 시 홈 등 추가 읽기와 전체 저장/검증/백업이 잠금을 점유한다. 특히 연속 자동 공격이 고빈도 후보. 오래된 예약도 보조 파일을 먼저 읽는다. ensureGuildTerritoryWar가 레거시 이관 시 직접 저장하므로 단순 로드 순서 변경은 최종 제외했다.
- 서버레이드: 평소 ACTIVE를 2초마다 읽는 구조가 아니라 준비/종료 마감 예약. 정산·실패 시 2초 재시도에서 회원과 분리 레이드 전체를 읽는다. 공지는 한 묶음 캐시·별도 영수증을 사용하지만 다른 회원 저장이 캐시를 무효화해 재읽기가 가능하다. 대용량 레이드 로그가 원인 후보. 전송 API는 잠금 밖이며 영수증·정산 복구는 삭제하지 않음.
- 미니게임: 미완료 자동 굴림·지급·공지 등이 있을 때 30초 재시도. 다른 콘텐츠 pending 파일 8개를 전체 파싱해 차단 상태를 확인하므로 큰 복구 원문이 남으면 부담. 실제 미완료 작업이 없으면 회원 로드 전에 반환한다. 복구 검증/저장 원문은 유지.
- 펫무쌍: 30초 스케줄 감시는 지정 분 외에는 파일 IO 없음. 지정 분에는 회원을 먼저 읽고 중복 회차/비활성 이벤트 확인 후 전투 자료를 로드하도록 보완(보조 파일 4개 생략). 모집·12초 턴 타이머는 회원 활성 상태/토큰 검사 후 펫·스킬·길드(모집은 홈 포함)를 로드하도록 보완. 정상 실행 저장·타이머 기한·보상 계산은 유지.
- 맞짱필드 /휴식: 3분 후 1회 회원 전체 읽기·저장. 이 콜백은 명시적 컨텍스트 캡처/데이터 잠금 없이 read-modify-save하므로 성능 외 동시 저장·DEV 컨텍스트 위험도 별도 후속 점검 대상. 이번에 동작 변경하지 않음.
- 프리미엄 만료: 타이머가 아니라 명령 공통 진입에서 만료 대상이 있을 때 활동·스킬·홈·가구를 읽고 회수/저장. 평상시 전원 전체 파일 저장을 반복하지 않는다. 만료와 복구가 겹치면 단발 지연 가능.
- 퀘스트·드라마·추리소설·할로윈·인형·길드마블·미니펫강탈·패키지/순위: 자체 주기 타이머는 확인되지 않았고 명령/공통 복구 진입에 의한 작업. 중단된 pending이 남으면 일반 명령에서도 실제 복구가 필요해 IO가 커질 수 있다. 대기 증거를 지우거나 검사/복구를 생략하지 않음.
- 새 길드전쟁: 이전 ver_2.769의 이벤트 기반 예약과 정액 보상 유지. 평시 금광 분당 적립·저장은 없음. 진행 중 전투 마감·미완료 공지·복구 재시도에서만 작업.
- notice.js: 70분마다 독립 알림 파일을 읽고 다음 시각을 저장. 게임 전체 데이터/백업을 읽지 않음. 당근 거래·소식 초안 만료와 지연 뽑기 응답도 대용량 파일 IO 없음. Info.js와 miniGameBot.js에는 자체 타이머 없음.

- 펫무쌍 3개 진입 함수에서만 불필요한 보조 파일 읽기를 줄였다. 저장·로드·백업·롤백·자동/수동 복구 및 업무 계산 함수는 변경 전과 동일함을 함수 외 소스 비교로 확인.

- node --check main.js / Info.js 통과. Rhino 1.7.15에서 main.js / Info.js / notice.js / data/miniGameBot.js 전체 compileString 통과. git diff --check 통과.

- 운영 데이터 파일·백업·로그·복구 기록은 수정하거나 삭제하지 않음. 기획 정책·보상·기한·/리셋 기준과 명령 목록도 변경 없음.
