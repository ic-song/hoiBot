# 위험한 명령어 가드

넓은 prefix 조건은 사용자가 채팅에서 사용법을 설명할 때 실제 명령을 실행할 수 있다.

## 위험한 패턴

```js
msg.startsWith("/명령어")
msg.indexOf("/명령어") === 0
```

특히 다음 명령어에서 위험하다.

- 아이템 소모
- 포인트 사용
- 인벤토리 판매 또는 제거
- 장착 또는 해제
- 확인 흐름 시작
- 게임 데이터 변경

## 더 안전한 패턴

정확한 명령어만:

```js
msg === "/명령어"
```

정확한 명령어 또는 숫자:

```js
msg === "/명령어" || /^\/명령어\s+\d+$/.test(msg)
```

숫자 필수:

```js
/^\/명령어\s+\d+$/.test(msg)
```

숫자 두 개:

```js
/^\/명령어\s+\d+\s+\d+$/.test(msg)
```

## 검증 케이스

가드 수정 시 다음 예시를 확인한다.

```text
/명령어방법
/명령어 1 해볼래
/명령어 10 알려줘
```

이 입력들은 mutation logic을 실행하면 안 된다.
