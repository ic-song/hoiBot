# 명령어 등록부 규칙

`COMMAND_REGISTRY.md`는 사람이 보는 체크리스트다.

## 규칙

- 현재 코드가 진실의 원본이다.
- 등록부는 명령어, source file, `미사용`, `삭제유무`, `비고`를 추적한다.
- 체크되지 않은 `미사용`은 기본적으로 사용 중으로 본다.
- `미사용`은 삭제 승인 의미가 아니다.
- `삭제유무`는 실제 source-code removal을 확인한 뒤에만 체크한다.
- 같은 조건 안에서 `||`로 연결된 값은 같은 명령어의 alias일 수 있다.
- 넓은 outer gate를 alias로 보지 않는다.
- 별도 `else if` 분기를 같은 명령어 그룹으로 묶지 않는다.
- alias와 trigger note는 `비고`에 적는다.
- lifecycle state나 verification level을 추가하지 않는다.

## 삭제

명령어 코드는 사용자가 명시적으로 삭제를 요청하고 source impact를 재검증한 경우에만 제거한다.
