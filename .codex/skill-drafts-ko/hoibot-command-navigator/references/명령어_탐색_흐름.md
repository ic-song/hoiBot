# 명령어 탐색 흐름

hoiBot 명령어를 탐색하거나 수정할 때 사용하는 체크리스트다.

## 탐색

1. `COMMAND_INDEX.md`가 있으면 먼저 확인한다.
2. 실제 소스는 `rg`로 검색한다.
   - 명령어 문자열
   - alias
   - 출력 문구
   - helper 이름
   - 아이템 이름
3. 실제 분기 조건을 `main.js` 또는 `Info.js`에서 확인한다.
4. helper 호출, 데이터 필드, 저장 호출을 추적한다.
5. 확실하지 않은 부분은 없음이 아니라 미확인으로 기록한다.

## 탐색 결과에 포함할 것

- 검색한 키워드
- 발견한 파일과 함수
- 관련 helper
- 데이터 사용
- 저장 흐름
- 불확실한 영역
- 중복 가능성이 있는 로직

## 문서 동기화

`COMMAND_INDEX.md`는 검증된 코드 기준으로만 수정한다.

색인에 없다는 이유만으로 명령어가 없다고 판단하지 않는다.
