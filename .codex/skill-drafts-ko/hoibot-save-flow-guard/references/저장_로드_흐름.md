# 저장/로드 흐름

persistence 변경 시 read path와 write path를 모두 확인한다.

## 확인

- 어떤 data object를 load하는지
- 어떤 variable을 mutate하는지
- 어떤 path에 save하는지
- surrounding response flow에서도 save하는지
- 여러 file을 함께 save해야 하는지

## 흔한 위험

명령어 하나가 다음 데이터를 변경할 수 있다.

- `data`
- `petData`
- `guildData`
- `petSkillData`
- home 또는 mini-pet data

각 mutation은 올바른 persistence path가 필요하다.
