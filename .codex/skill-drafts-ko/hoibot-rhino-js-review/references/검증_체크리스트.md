# 검증 체크리스트

## JavaScript Syntax

실행:

```bash
node --check main.js
node --check Info.js
```

작업 범위가 좁으면 변경된 파일만 실행한다.

## 런타임 한계

일부 명령 흐름은 Android MessengerBot API가 필요해서 Node에서 완전 검증할 수 없다.

검증하지 못한 런타임 영역은 명확히 보고한다.

## 검토 포인트

- modern runtime assumption 없음
- 의도하지 않은 save-flow 변경 없음
- 무관한 formatting churn 없음
- 사용자-facing 출력 형식 보존
