# 운영 반영

운영 반영은 검증된 작업을 `feature/prod`로 옮기는 작업이다.

## 필수 확인

- 현재 브랜치
- 작업 트리 상태
- 반영할 커밋
- unrelated commits 존재 여부
- 수행한 검증

## 안전한 반영

작업 브랜치에 관련 없는 커밋이 있으면 검증된 task commit만 cherry-pick한다.

`feature/prod`에 반영한 뒤 관련 검증을 실행하고 `feature/prod`를 push한다.

## 커밋 메시지

한글 요약을 사용한다.

좋은 예:

```text
명령어 안내 문구 오작동 방지
git-agent 운영 반영 규칙 추가
상점 구매 수량 검증 보강
```
