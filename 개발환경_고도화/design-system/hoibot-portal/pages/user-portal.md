# 이용자 포털 페이지 오버라이드

기준: `ui-ux-pro-max` 검색 결과와 2026-09-10 이용자 화면 검토를 반영한다. 이 문서는 `MASTER.md`의 브랜드 색과 기본 접근성 규칙을 유지하면서 `/login`, `/app`의 정보 구조와 밀도만 구체화한다.

## 화면 원칙

- 익숙한 계정 포털 구조를 사용한다. 데스크톱은 224px 컴팩트 사이드바와 본문 카드 영역, 모바일은 상단 사용자 카드와 2열 메뉴를 사용한다.
- 사이드바 메뉴는 콘텐츠 높이만 차지하며 남는 세로 공간으로 늘어나지 않는다.
- 첫 화면에서 계정 상태, 시스템 계정, 보안 상태, 게임 프로필을 한 번에 확인할 수 있게 배치한다.
- 준비 중 기능은 비활성 메뉴와 보조 문구로 구분하고, 동작하는 링크처럼 보이게 만들지 않는다.
- 카드 간격은 12~14px, 내부 여백은 18~20px로 통일한다. 본문 최대 폭은 1240px이며 고정 폭을 강제하지 않는다.
- 모든 입력과 버튼은 최소 44px 높이, 인접 조작 요소는 최소 8px 간격을 유지한다.
- 375px, 768px, 1024px, 1440px에서 가로 스크롤이 없어야 한다.
- 키보드 포커스를 항상 표시하고 `prefers-reduced-motion`을 존중한다.

## 페이지별 구성

### 로그인

- 데스크톱에서는 안내와 폼을 하나의 960px 이내 카드로 묶는다.
- 모바일에서는 안내가 먼저, 로그인 폼이 다음에 오며 입력 레이블과 오류를 입력 가까이에 표시한다.

### 계정 홈

- 상단에 페이지 제목과 연결 상태를 배치한다.
- 요약 카드 3개에 웹 계정, 시스템 계정, 보안 상태를 표시한다.
- 아래 영역은 게임 프로필과 이용 안내를 2열로 배치하고 작은 화면에서는 1열로 전환한다.
- 사이드바는 데스크톱에서 콘텐츠 높이만 사용하고 화면 상단 88px 아래에 고정한다.

## 금지 사항

- 메뉴 항목을 남는 높이만큼 늘리지 않는다.
- 실제 API가 없는 값을 임의의 통계나 활동 내역으로 표시하지 않는다.
- 준비 중 기능을 클릭 가능한 카드로 표현하지 않는다.
- 장식용 대형 문구로 핵심 계정 정보를 화면 아래로 밀지 않는다.
