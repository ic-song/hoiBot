# 계정 연결 상세 페이지 오버라이드

`MASTER.md`와 `pages/user-portal.md`를 따르며 `/account`, `/account/links`에 아래 규칙을 추가한다.

- 현재 로그인한 본인의 연결 정보만 표시한다.
- 로그인 ID는 기존 마스킹 규칙을 사용하고 내부 account/player 식별자는 화면에 표시하지 않는다.
- 연결 상태, 웹 로그인 ID, 시스템 계정, 현재 게임 프로필, 서버를 첫 카드에서 확인할 수 있게 한다.
- 연결 해제와 계정 전환은 구현된 API가 없으므로 버튼으로 만들지 않고 준비 중 안내만 표시한다.
- 데스크톱은 사이드바와 상세 카드를 사용하고, 620px 미만에서는 상세 항목을 2열에서 1열로 자연스럽게 줄인다.
- 모든 링크는 44px 이상의 터치 영역과 키보드 포커스를 유지한다.
- 인증된 화면에서 세션이 만료되면 계정·프로필 값을 즉시 지우고 로그인 화면으로 이동한다.
- 만료 안내는 화면에 직접 표시하고 `role="status"`와 포커스를 함께 제공해 키보드·스크린리더 사용자도 상태 변화를 확인할 수 있게 한다.
- 첫 방문의 미로그인 상태와 사용 중 세션 만료를 구분하며, 첫 방문에는 불필요한 만료 경고를 표시하지 않는다.
