# 계정 연결 상세 페이지 오버라이드

`MASTER.md`와 `pages/user-portal.md`를 따르며 `/account`, `/account/links`에 아래 규칙을 추가한다.

- 현재 로그인한 본인의 연결 정보만 표시한다.
- 로그인 ID는 기존 마스킹 규칙을 사용하고 내부 account/player 식별자는 화면에 표시하지 않는다.
- 연결 상태, 웹 로그인 ID, 시스템 계정, 현재 게임 프로필, 서버를 첫 카드에서 확인할 수 있게 한다.
- 연결 해제와 계정 전환은 구현된 API가 없으므로 버튼으로 만들지 않고 준비 중 안내만 표시한다.
- 데스크톱은 사이드바와 상세 카드를 사용하고, 620px 미만에서는 상세 항목을 2열에서 1열로 자연스럽게 줄인다.
- 모든 링크는 44px 이상의 터치 영역과 키보드 포커스를 유지한다.
- 인증된 화면에서 세션이 만료되면 계정·프로필 값을 즉시 지우고 로그인 화면으로 이동한다.
- 만료 안내는 화면에 직접 표시하고 `role="status"`와 포커스를 함께 제공해 키보드·스크린리더 사용자도 상태 변화를 확인할 수 있게 한다.
- 첫 방문의 미로그인 상태와 사용 중 세션 만료를 구분하며, 첫 방문에는 불필요한 만료 경고를 표시하지 않는다.

## 관리자 회원 상세 오버라이드

관리자 회원 상세의 `/admin/players/:playerId/account-links`는 기존 관리자 셸 규칙을 따르며 아래 규칙을 추가한다.

- 회원 목록에서 선택한 상세 화면 안에 계정 연결 정보를 읽기 전용 패널로 표시하고, 직접 URL 진입과 새로고침에서도 같은 회원을 복원한다.
- 로그인 ID와 외부 사용자 키는 API가 제공한 `maskedLoginId`, `maskedExternalUserKey`만 표시한다. portal account ID, link ID, selection version과 원문 식별자는 표시하지 않는다.
- 연결 없음, 회원 없음, 권한 부족, 세션 만료, 일반 조회 실패를 서로 구분하며 실패 상태에는 동일 조회 재시도만 제공한다.
- 연결 상태, 계정 상태, 역할, 플랫폼, 문맥, 선택 상태는 텍스트와 함께 표시하며 색상만으로 의미를 전달하지 않는다.
- 연결 해제, 계정 전환, 편집 등 mutation 버튼은 두지 않는다.
- 회원 선택 버튼은 44px 이상의 터치 영역과 명확한 키보드 포커스를 제공하며, 선택 후 계정 연결 제목으로 포커스를 옮긴다.
- 640px 이하에서는 연결 상세를 2열에서 1열로 줄이고 긴 마스킹 문자열은 카드 안에서 줄바꿈한다.
