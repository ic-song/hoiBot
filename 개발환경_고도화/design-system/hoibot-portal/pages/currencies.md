# 재화 화면

`/account/currencies`는 현재 로그인한 이용자의 재화 잔액을 보여 주는 읽기 전용 화면이다.

- `GET /api/v1/player-profiles/current`의 기존 `profile.currencyAccounts`만 사용한다. 별도 재화 API, provider, 인증 흐름을 호출하지 않는다.
- `point`는 `포인트`, `diamond`는 `다이아`로 표시하고, 그 밖의 코드는 원문을 표시한다.
- 잔액은 문자열 그대로 표시한다. 숫자 변환, 반올림, 자릿수 축약을 하지 않는다.
- 로딩·빈 목록·조회 오류를 각각 표시하고, 401 응답은 기존 세션 만료 처리로 민감한 목록을 지운 뒤 로그인 화면으로 전환한다.
- 카드 목록은 375px부터 한 열로 흐르고 긴 코드와 큰 잔액은 줄바꿈한다. 탐색 링크와 버튼의 최소 높이는 44px 이상이며, 현재 페이지에는 `aria-current="page"`를 제공한다.
