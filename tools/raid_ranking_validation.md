# 레이드 공격 개인 정렬 생략 단독 반영

- 기준: `96633c05` / `ver_2.664`
- 반영 준비 버전: `ver_2.665`, 2026-10-21 KST
- 범위: 공격 안내의 개인 순위 정렬 생략만 포함. PR #138의 저장 원문 재사용과 응답 전송 잠금 변경은 별도 검토 상태로 보존한다.

공격 안내에 필요한 서버 합계와 공동 순위는 기존 함수로 계산한다. 개인 순위 조회와 종료 정산의 개인 정렬은 유지하며, `freeze === true`는 생략 옵션과 무관하게 개인 순위·기여도·상금·핸디캡을 확정한다. 회원/회차 읽기·저장·백업·공지·응답 전송은 기준과 동일하다. 신규 명령과 데이터 형식은 없다.

`tools/test_raid_ranking.js`는 main 전체를 기준과 비교하여 버전 및 이 정렬 변경 외의 실행 코드 차이가 없음을 단언한다. 1,500명의 합성 참가자, 안전 정수보다 큰 피해 합계, 공동 순위, 공격 없는 계정, 0 피해, 빈 회차, 잘못된 피해, 기존/공격권/이전 보상 기준 UI와 정산 전체를 대조했다. 공격 안내의 순위 정렬 호출은 서버용 1회이며, 조회/정산은 개인 정렬을 유지한다.

검증 명령:

```powershell
node --check main.js
node --check Info.js
node tools/test_raid_ranking.js
node tools/test_server_raid.js
node tools/test_server_raid_oct12.js
node tools/test_server_raid_delivery_rhino.js <rhino-1.7.15.jar>
node tools/test_raid_ranking_rhino.js <rhino-1.7.15.jar> <ranking-result.json>
```

Node는 신규5 + 기존130 + 추가 정책11 =146그룹을 통과했다. 기존 레이드 검증에는 실제 7인수 콜백, 중복 이벤트, 저장 실패 원복, 재시작, DEV, 공격권, 치명타, 상금·핸디캡 정산이 포함된다. Rhino 전체 MAIN/Info 컴파일과 공지·실제 Java 동시성/저장·재시작9시나리오도 검증한다.

별도 실제 Rhino 인터프리터의 합성 공격 문구 생성 중위(준비5회·측정10회, 정렬된 표본 인덱스5):

| 참가자 | 기준(ms) | 단독 수정(ms) |
| --- | ---: | ---: |
| 100명 | 10.55 | 11.54 |
| 1,000명 | 30.24 | 29.33 |
| 5,000명 | 266.29 | 77.77 |

전후 메시지와 최종 정산 객체가 일치했다. 소규모 개선은 편차로 확정하지 않는다. 이 값은 PC 합성 시험이며 저장·네트워크·운영 Android 응답 시간을 포함하지 않는다. 원본 표본은 `tools/raid_ranking_prod_result.json`에 보존한다. 시험 하니스에 빠진 `normalizeHoiServerLabel` 의존성을 실제 소스에서 포함한 뒤 통과했다. 운영 코드를 이 문제로 변경하지 않았다.

운영 반영은 검증 소스 푸시→PR→`feature/prod` 원격 확인 절차로 수행한다. 운영 앱 업로드·컴파일·재시작은 운영자가 진행한다.
