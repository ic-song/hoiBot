# 호이님 코드 작업 안내

이 문서는 Git 명령어를 직접 사용하지 않고, 배치파일을 통해 코드 작업을 진행하는 방법을 정리한 안내문입니다.

---

## 1. 기본 작업 흐름

코드를 추가하거나 수정할 때는 아래 순서로 진행합니다.

```text
01_새작업시작.bat 실행
↓
main.js 또는 Info.js에 코드 붙여넣기
↓
파일 저장
↓
02_수정내용올리기.bat 실행
↓
feature/prod 운영 반영 확인
```

---

## 2. Codex Skills 설치/업데이트

작업 환경이 바뀌었거나 새 PC/새 Codex 환경에서 작업할 때는 아래 배치파일을 실행합니다.

```text
05_skills_설치.bat 실행
```

이 배치파일은 저장소에서 관리하는 Codex skill 원본을 로컬 Codex 설정 폴더로 동기화합니다.

```text
저장소 원본: .codex/skills/
로컬 사용:  %USERPROFILE%\.codex\skills\
한글 검토본: .codex/skill-drafts-ko/
```

언제 실행하면 좋은가요?

- 작업 환경이 바뀌었을 때
- 저장소를 새로 clone 했을 때
- `.codex/skills/` 내용이 변경되었을 때
- Codex가 hoiBot 전용 작업 규칙을 못 따라오는 것처럼 보일 때

---

## 3. 배치파일 목록

| 파일 | 용도 |
| --- | --- |
| `01_새작업시작.bat` | 새 코드 작업을 시작할 때 사용합니다. |
| `02_수정내용올리기.bat` | 수정한 내용을 저장소에 올리고 `feature/prod`에 직접 병합/push합니다. |
| `03_main_운영반영.bat` | 최신 `feature/prod`의 `main.js`를 LD플레이어 운영 봇에 반영합니다. |
| `04_info_운영반영.bat` | 최신 `feature/prod`의 `Info.js`를 LD플레이어 운영 봇에 반영합니다. |
| `05_skills_설치.bat` | 저장소의 Codex skills 원본을 로컬 Codex 설정 폴더로 설치/업데이트합니다. |
| `99_주의_망했을때_처음으로.bat` | 작업 상태를 되돌려야 할 때 주의해서 사용합니다. |
