## 동작과 저장

`/미니펫컬렉션전체등록`은 무인수 정확 일치일 때만 실행한다. `selectMiniPetCollectionLowest`는 본인 미니펫 가방을 한 번 순회해 허용8등급 중 빈 등급별 최저 `battleExp`를 선택한다. 같은 매력은 먼저 나온 개체를 유지한다. 대표/보조 장착 슬롯과 비허용 등급은 선택하지 않는다. 3,000개 전체를 출력하거나 모두 강화하지 않으며 실제 후보는 최대8마리다.

미리보기는 가방·컬렉션 파일을 저장하지 않는다. 선택 목록·현재 단계·소모 경고·자동 강화/확률에 따른 비용 변동·등록/ㄴㄴ를 안내한다. 확인 상태는 DEV/PROD·계정별 메모리에 60초 유지하고, 같은 방/채팅 유형에서만 응답한다. 가방 전체나 본인 컬렉션이 바뀌면 재선택하도록 취소한다. 유효 확인은 대기를 먼저 지우고 기존 등록 처리로 넘긴다. 실패·중복·재시작은 같은 선택을 다시 소비하지 않는다. 다른 수동/만능 컬렉션 확인과 공통 응답이 충돌하지 않도록 새 선택 의도를 우선한다.

자동 강화 확률·비용·최고 확률UP 아이템·개통령 조건, 등급/단계 보상·타이틀·시즌80 종료는 기존 함수를 재사용한다. 현재 단계를 완료하면 다음 단계 재료를 소비하지 않는다. 일부 성공 후 다른 강화가 실패한 경우도 실제 소비 비용을 합계에 표시한다. 전부 실패한 경우 기존 등록의 무저장 반환을 유지한다.

저장 순서는 기존 컬렉션 → 타이틀 → 회원 → 펫이다. 기존 전역 보호 목록에는 앞 두 파일이 없어, 전체등록에서 읽은 원문을 명시적 스냅샷으로 전달해 기존 트랜잭션에 포함한다. 회원/펫은 기존 보호 저장·백업을 유지한다. 파일 파싱 오류를 기본값으로 숨기지 않는다. 저장 예외 시 네 원본을 복원하며, 저장 실패 후에는 새 전체등록 요청이 필요하다. 기존 수동/만능 등록 경로는 변경 전 저장 방식과 동작을 유지한다.
