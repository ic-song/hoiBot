# 미니게임 공통 처리의 불필요한 순회 축소

- 기준: `1157868c496015b33c5ac37814543de0e6bcc96d` / ver_2.717 → ver_2.718, 2026-10-27 KST.
- 개인 명령의 주사위 화면 후보를 전체 사용자에서 본인 한 명으로 좁혔다. 주사위 외 명령·재표시는 후보 0명이다. 저장 모델의 객체를 그대로 참조하므로 전송 성공 후 단계 변경·저장에 같은 객체가 사용된다. 자동 처리는 기존 전체 순회와 순서를 유지한다.
- `getMiniGameWorkDelay`는 첫 RESULT 또는 밸런스 외 PENDING 보상을 찾으면 간격을 즉시 반환한다. 이 두 조건은 모두 같은 고정 재시도 간격을 사용하므로 이후 항목으로 더 짧아질 수 없다. 기존 `Math.max(1, Math.min(dayMs, retryMs))` 계산은 유지한다. 호출은 전체 상태 검증·지급·공지 처리가 끝난 뒤이며 데이터 검증을 이 함수로 대체하지 않는다.
- `requireMiniGameState`, `payMiniGameRewards`, 공지 CLAIMED→SENT/UNCERTAIN, `commit`, 저널 복구, 보상·난수·횟수·리셋·캐시·DEV/PROD 경로·잠금·7인수 콜백은 변경하지 않는다. 회원/보관/진행 게시 및 저널 정리 경계를 유지하고 파일 누락·파싱·손상 오류를 숨기지 않는다.
