## 적용 정책

- 하루 전체 금고 10개 → 15개. 1~3개 쉬움 2억, 4~7개 보통 5억, 8~15개 어려움 10억으로 총 106억. 기존 10개 종료 상태도 기지급 보상을 보존하고 11번째로 이어진다.
- 수동 `/금고리셋`은 새 게임 ID·비밀번호로 첫 금고를 열고 진행·금일 당첨 목록·힌트·모든 계정의 사용 횟수·재응답 대기를 함께 초기화한다. 완료 표시는 0/15. 종료 후에도 리셋 가능하다. 미지급 보상이 있으면 리셋을 보류한다.
- 지급된 포인트·원장·보상 증거는 보존한다. 기존 게시 저널과 원자 파일 교체를 재사용하여 진행과 보관 파일을 함께 확정·복구한다. 별도 저장 체계나 스냅샷 초기화는 추가하지 않았다.
- 기획서가 기존 정책으로 적은 개인 2/3회는 실제 운영 코드와 달랐다. ‘기본 횟수 및 패스 혜택 변경 없음’에 따라 운영의 일반/일반 패스 3회·프리미엄 5회를 유지했다. 일반 `/리셋`과 시각 기반 초기화 로직은 변경하지 않았다.
- 금고털이범은 A등급·기존 A 고정 확률 0.4%·장착 보너스 2회, 경제사범은 한정판 등급·일반 오픈 제외·장착 보너스 4회다. 두 신규 스킬은 큰 보너스 하나만 적용한다. 동일 스킬 중복·가방 보유·프리미엄 잠금은 추가 가산하지 않는다. 기존 확률 정책대로 D등급 잔여 총확률은 41.1%에서 40.7%로 줄어든다.
- 사용자 확인: 괴도루팡 ↔ 경제사범은 합산 허용. 현재 소스·스킬 카탈로그에는 괴도루팡 정의/효과가 없으므로 임의로 신규 등록하거나 보너스 값을 만들지 않았다. 이 두 이름의 장착을 막는 제약도 추가하지 않았다.
- 실제 장착 데이터는 명령 진입에서 한 번 읽고 계산 함수에 전달한다. 탈착·교체·패스 변경 후에도 이미 사용한 횟수는 보존한다. 최대 9회를 사용한 뒤 해제·프리미엄 만료가 발생해도 저장 검증이 실패하지 않으며 남은 횟수는 0 아래로 내려가지 않는다.
