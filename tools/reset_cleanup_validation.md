| 추가 항목 | 기존 권한 | 유지하는 정리 기준 |

| `[정리] 글자수 전체 정리` | 기존 MASTER 또는 GM 관리자방 Admin·오픈채팅봇 | 미니펫은 매력·등급·이름순, 가구는 매력·이름·ID순으로 일반 10개·활성 프리미엄 15개 보관. 펜던트는 기존 등급·이름순으로 50개 보관. 초과분만 삭제하며 장착·재화 유지 |
| `[정리] 필터 데이터 정리` | 기존 방별 Admin·MASTER | 확인 시점 등록 필터의 문자열 포함 규칙으로 전체 일반·픽 댓글, 피드·이전 한줄평, 일반·펫 타이틀과 관련 알림만 제거. 필터 목록·방문·누적 통계·가구·재화 유지 |

- 각 단계 60초 만료, 사용자·방·그룹·DEV/PROD 분리, 재컴파일 취소, 최종 확인 1회 소비와 권한 재검사를 그대로 사용한다.
- 메뉴·선택은 회원·길드만 읽고 정리 대상 파일을 읽거나 저장하지 않는다. 확인 후 최신 데이터·프리미엄 여부·필터로 원래 분기를 실행한다.
- 정리 계산 함수, 원래 정리 실행 분기와 이후 게임 실행·저장·이벤트 제한 본문은 기준 소스와 동일하다. 새 저장 경로나 복구 방식을 추가하지 않았다.
- Info는 새 글자수 정리 안내 입력에서도 중복 읽기·응답 없이 반환한다.
- `/데이터정리`, `/정리`, `ㅇㅇㅇ`, 개인 가방 정리·판매, 개별 미니펫·가구·펜던트 전체 정리, 정기 리셋과 별도 알림 스크립트는 유지한다.

## 적용 경계

- 실제 Android MessengerBot·운영 데이터에서는 실행하지 않았다. 검증은 합성 데이터와 가상 파일 IO, 실제 저장/롤백 함수 및 Rhino 실제 Java 잠금으로 수행했다.
- 글자수 검증은 실제 메뉴 진입부·정리 분기·저장을 연결한 합성 실행이며 전체 일반 게임 전처리의 실기기 실행을 대신하지 않는다. 이후 원래 게임 처리 본문은 기준 소스와 동일함을 별도 비교했다.
- 앱 강제 종료 시 여러 파일의 원자성은 기존 방식과 같다. 추가 영속 세션이나 저널은 없다.
- 운영반영 시 Main·Info를 함께 적용한다. 실제 업로드·컴파일은 운영자 영역이다. 승인된 Git 반영의 커밋·원격 확인·카카오 알림 결과는 작업 체크포인트에 기록한다. 기존 LIVE 기획서는 이번 메뉴 통합의 READY/HOTFIX 항목이 아니므로 변경하지 않는다.
