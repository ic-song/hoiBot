# 영지전 명령 제한 검증

- 검증일: 2026-10-26 (Asia/Seoul)
- 브랜치: `feature/territory-command-lock`, 기준 `ver_2.710`
- 목표: 진행 중인 환경에서는 영지전 관련 명령과 정확한 `/글자수전체정리`만 통과시킨다. 각 명령의 기존 권한·방·인자 조건은 유지한다.

## 확인 결과

- 기존 Main 판별 함수에서 `ㅊㅊ`가 차단되지 않고 `/디버깅모드`가 허용되는 것을 재현했다.
- Main은 DEV 단축어 정규화 후, 초기화·필터·교육·미니게임 등 개별 진입보다 먼저 검사한다. Info는 공통 회원·펫·타이틀 읽기 전에 종료한다. 운영자·운영봇·전역 정보 예외도 통과하지 않는다.
- 영지전 상태 조회가 실패하면 기존 오류 흐름으로 실패한다. 초기화 확인 입력이었다면 대기를 해제하여 오류 뒤 남은 확인 요청이 실행되지 않게 한다.
- PROD/DEV 각각의 상태를 따른다. 영지전이 끝나면 일반 입력은 원래 흐름으로 통과한다.

- 합성 파일·계정과 로컬 Rhino를 사용했다. 운영 데이터와 운영 기기는 변경하지 않았다.
