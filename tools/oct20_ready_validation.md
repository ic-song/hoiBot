## 3. 주문기록방 권한

기획: [주문기록방_권한_적용_기획서](https://www.notion.so/c65393bdd7aa83c68e1c81a087f465ff)

- 133개 조건을 기준 커밋과 대조해 일반 사용자·기존 운영자·다른 방의 봇에 대한 결과가 같고 주문기록방 봇은 기존 운영자와 같은 결과임을 실행 확인했다.
- 일반 사용자에게 역할을 주거나 봇을 영구 명단에 등록하지 않는다. 수신 `sender`/회원 키를 다른 운영자로 치환하지 않는다. 실제 기록 명령에서도 발신자가 오픈채팅봇으로 유지된다.
- Main·Info의 실제 공통 약관 제한 분기와 관리 명령 분기를 실행해 해당 방 봇의 명령 접수를 확인했다. 기존 봇 수신 길이 예외는 유지한다.
