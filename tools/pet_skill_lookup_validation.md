## 구현과 보존 조건

`getPetSkillData`는 기존 정규화와 순차 검색을 유지한다. 성공한 조회만 정규화 이름으로 함수 객체의 조회표에 보관하고, 같은 소스 정의 객체를 반환한다. 첫 번째 일치가 우선이며 빈 이름, 티어 이모지 생략 이름, 옛 별칭도 기존 결과를 유지한다. 알 수 없는 이름은 보관하지 않아 입력에 비례해 조회표가 계속 커지지 않는다. 개인 스킬·가방·장착 상태는 보관하지 않는다.

현재 `PET_SKILL_LIST`는 소스 상수이며 운영 코드에서 목록 추가·삭제·재정렬이나 이름 변경을 하지 않는다. 목록 참조나 길이가 바뀌면 조회표를 교체하고, 소스를 다시 로드하면 새 함수와 조회표를 사용한다. 정의의 효과 등은 복사하지 않고 원래 객체의 참조로 반환한다. 향후 소스 정의를 실행 중 제자리 변경하는 기능을 추가한다면 그 시점에 별도 무효화 정책을 검증해야 한다.

`getPetSkillBagList`는 기존 초기화와 양수 수량 필터를 유지한 뒤, 각 이름의 정의와 목록 위치를 한 번 계산한다. 같은 이름 배열을 같은 Rhino `sort`로 정렬하며, 기존 정의 위치 차이와 한국어 이름 비교를 그대로 사용한다. 미등록 위치는 기존 `999`를 유지하고, 빈 가방과 한 종류 가방은 정의를 조회하지 않는다. 번호가 바뀌지 않으므로 장착·판매·컬렉션·거래가 참조하는 번호도 보존한다.
