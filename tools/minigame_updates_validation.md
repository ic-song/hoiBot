## 길드마블

- 기존 권한의 `/리셋` 실행 시 현재 방·소속에 관계없이 관리 중인 전체 길드 저장소를 처리한다. 모집은 취소하고, PLAYING은 REFUND로 확정해 참가비 전액 환급·수수료 없이 종료한다. 길드 일일 이용 횟수는 별도로 초기화하지 않는다.
- 이미 SETTLING인 경기는 확정된 종류·상금·환급액·부분 지급 증거를 유지한다. 계정 ID로 미지급만 처리하며 삭제 계정, 같은 닉네임의 신규 계정, 지급 후 포인트 범위 초과는 오지급 없이 대기한다.
- 지급 불가 경기는 SETTLING으로 보존되어 이전 차례를 진행할 수 없다. 기존 정산 재시도 또는 다음 `/리셋`에서 처리하며 실제 종료·취소·정산 대기 건수를 구분한다.
- 기존 guildMarblePending 형식에 원래 회원 원문과 모집 취소·정산 대기 전환이 확정된 경기 원문을 먼저 남긴다. 회원/경기 게시 도중 종료되어도 복구 후 PLAYING으로 되돌아가지 않고 미지급만 처리한다. 기존 경기·회원 게시 방식과 복구 경로를 재사용한다.
- `/리셋`을 DEV 포함 배타 데이터 변경으로 분류한다. 타이머·자동 감시·신규 명령은 추가하지 않는다. 안내는 실제 실행 기준인 일일 `/리셋`을 사용한다.

## 호월주사위

- 프리미엄 하루 4판·공정한 1~6 주사위·기본 승/무/패 3천만/2천만/1천만·두 입력/두 메시지를 유지한다.
- 럭키 식스(내 주사위 6+6) +5천만, 역전승(첫 굴림 열세·최종 승리) +2천만, 정확히 2/3/5연승 달성 시 +1천만/+3천만/+1억. 무승부는 연승 유지·연승 보너스 재지급 없음, 패배는 0, 6연승 이후 추가 보너스 없음. 럭키 식스+역전승은 조건상 동시에 발생하지 않는다.
- 최종 결과 확정 시 경기 전후 연승·네 숫자·보너스 종류/금액·총액·지급 원장을 기존 미니게임 상태와 함께 저장한다. 보너스 계산은 실제 확정 숫자로 검증하며 지급 재시도는 연승을 재가산하지 않는다.
- 진행 중인 판과 연승은 방·날짜·재시작·길드마블 리셋으로 지우지 않는다. 일일 `/리셋`은 신규 시작 횟수만 갱신한다. 구버전 완료/기존 확정 보상은 그대로 유지하고 보너스를 소급하지 않는다.
- 두 화면 제목 아래 시작 전/결과 후 연승을 표시하며 0이면 생략한다. 두 화면의 안내는 공통 allsee 본문이다. 최종 본문은 보너스가 있을 때만 총액을 표시하고, 미지급이면 지급 대기·총 지급 예정으로 구분한다.
- 반응 문구는 주사위 난수와 별도로 순환하고 확정된 문구를 재사용한다. 연승 성공은 호월이가 분해하는 반응, 연승 종료는 직전 연승 수로 장난치는 반응이다.
