# 일일 횟수의 `/리셋` 회차 통일 검증

- 기준: `origin/feature/prod` ver_2.705 → ver_2.706, 2026-10-26 KST.
- 사용자 확정: `리얼타임기준이아닌 /리셋 명령어 기준임`.
- 실제 Android 기기·운영 원본 자료에는 접근하지 않았다. 메모리 합성 자료와 OS 임시 폴더의 Java 파일만 사용했다.

## 변경과 보존

기존 `/리셋 → resetAttendance` 연결을 유지한다. 회원 파일의 `dailyResetCycle`을 명령 실행 때 한 번 증가시켜 별도 파일의 길드마블·마음표현·경량 출석이 같은 회차를 사용하게 한다. 회차가 없는 기존 기록은 0회차로 해석하므로 설치·달력 날짜 변경만으로 사용량을 지우지 않는다. 별도 파일을 일괄 재저장하지 않으며, 새 이용 때만 현재 회차의 사용 기록을 저장한다.

재벌도전은 날짜 비교 초기화를 제거하고 기존 `/리셋`의 기록 제거를 따른다. 채팅 경험치는 `/리셋`에서 사용 기록을 지우며 날짜 비교로 지급 한도를 복구하지 않는다. `/채팅경험치확인`도 지난 날짜 기록을 0으로 표시하지 않는다. 경량 출석을 회원으로 이관할 때도 같은 회차인지 판정한다.

기존 권한·입력 가드·잠금·DEV 경로·회원 분리 저장·저장 실패 롤백을 유지한다. 재벌 10회, 길드 7회, 마음 보너스와 운영자 예외, 채팅 1,000 EXP·가호 계산은 유지한다. 진행 중 경기·정산·기지급 기록·누적 출석과 받은 마음은 보존한다. 패스 만료일·날짜별 구독 보상·대회 일정·기간 타이머는 수정하지 않는다. 같은 날짜에 다시 실행한 권한 있는 `/리셋`도 기존 출석 동작처럼 새 회차를 부여한다.
