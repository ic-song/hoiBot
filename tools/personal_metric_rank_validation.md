# 개인 당근·온도 순위 정렬 축소

- 기준: `599375e9bd40dba6e4a4b69ec3740b599f98417f` / ver_2.716 → ver_2.717, 2026-10-27 KST.
- `Info.js`의 `/내정보`에서 사용하는 `getCarrotRank`·`getThermoRank`만 공통 개인 순위 계산에 연결했다. Main의 동명 함수는 호출처가 없어 원형을 보존했으며 Main은 버전만 변경했다.
- 양수 대상 필터를 그대로 적용한다. 유한한 숫자로 이뤄진 순위에서는 점수가 더 크거나 동점 닉네임이 앞선 회원 수를 세어 순위를 구한다. 정상 경로는 회원 수 N에 대해 O(N)이며 전체 정렬이 없다.
- 숫자 문자열·불리언·양의 무한대·양수로 변환되는 객체가 포함되거나, 다른 동점 닉네임이 본인과 `localeCompare(..., "ko") === 0`이면 기존 비교 함수와 엔진 정렬을 유지한다. 미등록/비양수 대상도 기존 정렬 경로를 유지한다. Rhino의 불안정 동점 정렬 결과와 기존 형변환을 임의로 바꾸지 않는다.
- 명령·점수·동점 기준·UI·파일 읽기·저장·DEV/PROD 경로·7인수 콜백은 변경하지 않는다. 조회 간 캐시는 없다. 데이터 오류를 기본값으로 복구하지 않는다.
