# 명령어 문구 필터 검증

## 필터 300개 상한 후속 검증 (운영 미반영)

- 운영 e7b0b1b0/ver_2.670에서 feature/filter-limit 분리. `GLOBAL_CONFIG.messageFilter.maxWords = 300`으로 신규 등록 상한 적용.
- 중복 제외 후 실제 신규 추가 결과가 300개를 넘으면 요청 전체를 거절한다. 파일·캐시는 바뀌지 않으며 일부만 추가하지 않는다. 300개에서 중복 추가는 무변경, 제거 후 새 추가 가능. DEV/PROD 상한은 독립적이다.
- 기존 초과 목록은 컴파일·조회·필터링을 유지하며 자동 삭제하지 않는다. 초과 상태에서도 중복 추가·제거는 허용하고 신규 추가만 거절한다. 기존 저장·백업·캐시 공유 함수는 그대로 유지한다.
- 필터 19그룹, 데이터 정리 12그룹, Rhino 9시나리오와 전체 컴파일·문법·UTF-8·diff 검증 통과. 기존 운영 데이터·버전 변경 없음. 실제 Android 앱에서는 실행하지 않았다.

## 필터리스트 후속 검증

- 운영 361ed98d/ver_2.669에서 feature/filter-list 분리. `/필터리스트`는 기존 방별 관리자·MASTER 권한으로 현재 환경의 캐시를 번호·등록 순서·총개수와 함께 표시한다. 빈 목록 안내, 필터 자기 차단 제외, Info 중복 처리 방지.
- 조회 파일 읽기/저장 0회. 기존 추가·제거는 쉼표만 구분자로 사용하며 문구 앞뒤 공백은 제거하고 내부 공백은 보존한다. 제거는 완전 일치하는 항목만 삭제한다.
- 필터 15그룹(목록 2그룹·구분자 1그룹 포함), 기존 데이터 정리 12그룹, Rhino 8시나리오와 전체 소스 컴파일 통과. 문법·diff 공백·엄격한 UTF-8 검사 통과. 운영 데이터·버전 변경 없음. 실제 Android 앱에서는 실행하지 않았다.
- 운영반영 승인 후 최신 운영 361ed98d 기준으로 재검증하고 버전·개발자노트를 ver_2.670으로 갱신했다. 게임 데이터는 변경하지 않는다.

## 기존 필터 기능 검증

- 기준: 2026-10-21, feature/message-filter, 운영 기준 9a86f146ae26a306144af276281d6e80ecea3851 / ver_2.667.
- 요구: 쉼표로 복수 문구 관리, 기존 관리자·MASTER 권한, 일치 시 무응답 중단, 컴파일 초기 캐시, 일반 대화 비교 제외. 댓글 삭제는 보류.
- 일반 명령 필터는 메모리만 조회한다. 관리 변경은 회원 저장 성공 후 Main·Info 캐시에 반영한다. DEV/PROD 분리, DEV 백업 시 캐시 갱신, 재컴파일 시 저장 목록 복원.
- 저장/복구 내부 함수는 기존 구현을 유지한다. 저장 실패 시 기존 파일·캐시 유지, 응답 실패 시 확정된 목록 유지. 실제 분리 회원 저장에서도 레이드·로그 데이터와 세대 표식이 유지된다.

## 적용 조건과 범위

- Main과 Info를 함께 업데이트한다. 관리 명령은 즉시 공유되며 파일 수동 수정은 Main 재컴파일이 필요하다.
- 실제 Android MessengerBot 앱에서는 실행하지 않았다. 개발 PC의 Node 합성 데이터와 Rhino/Java 임시 파일로 검증했다.
- 운영반영 승인에 따라 버전·개발자노트를 ver_2.668로 갱신했다. 필터 초기값은 비어 있고 과거 댓글이나 기존 게임 데이터는 삭제하지 않는다.
- 반영 직전 최신 운영 9a86f146 기준으로 필터 Node 12그룹·Rhino 7시나리오·저장 21그룹·당근거래 16그룹·메인방 제한을 다시 실행해 통과했다. 소스 버전과 개발자노트의 2.668 일치 및 운영 데이터는 개발자노트 외 무변경을 확인했다.
