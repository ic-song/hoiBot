## 기존 동작의 한계와 미검증 영역

- 현재 가방 한도는 시작 시 가방 수량으로 판정한다. 예를 들어 기본 10칸에서 9개를 보유한 채 3개를 열면 12개가 되는 기존 동작도 유지한다.
- 홈 데이터는 `FileStream.write`, 회원 데이터는 관리 JSON 검증 저장을 사용한다. 홈 저장 후 회원 저장 실패 시 회원은 원래 상태지만 홈에 지급 가구가 남는 기존 비원자적 저장 경계가 있다. 두 버전의 예외 후 상태가 같은지 검증했으며, 양쪽 파일이 함께 롤백된다고 보장하지 않는다. 저장 정책 변경은 이번 최적화에 포함하지 않는다.
- Android 기기에서의 실제 실행·메모리 부족 재현은 미검증이다. 운영 소스 반영은 Git `feature/prod`까지이며 업로드·컴파일은 운영자가 수행한다.
