# 순위 계산 중복 축소 검증

- 버전: `ver_2.692`, 2026-10-25.
- 기준 소스: `0c5f64f0d6f33bda59cb3eaa5c652c7b407179af` (`ver_2.691`).
- 사용자 제약: 기능 변경 금지. 명령·화면·매력 공식·개인/서버 순위·동점·입장권·입장 조건·보상·저장 결과를 유지한다.

## 최종 변경 범위

1. Info `/펫정보`와 두 별칭에서 본인 캐슬·레이드 매력을 표시·종합매력·개인 순위용으로 3번 계산하던 것을 1번으로 줄인다. 강화 매력은 2번에서 1번으로 줄인다. 원합계와 기존 표시용 `parseInt`/NaN 처리를 구분한다. 계산값은 응답의 지역 변수로만 전달하며 응답/회원/DEV 사이의 캐시는 추가하지 않는다.
2. `getMemberRank`는 선택 인자로 받은 유한한 본인 원합계만 재사용한다. 생략·비정상 값이면 기존 계산을 수행한다. 다른 회원의 계산 순서와 개인 순위의 **기존 정렬을 항상 유지**한다. Rhino 1.7.15의 동점 정렬은 입력 순서를 보장하지 않으므로 이 부분의 정렬 생략은 최종 구현에서 제외했다.
3. Main의 `isUserInTotalRankingTop`는 전체 점수 계산 순서를 그대로 유지하고 앞선 인원을 세어 상위 제한을 판정한다. 기존의 점수 내림차순·동점 닉네임 오름차순과 동일하며 비정상 점수는 기존 정렬로 판정한다. 누락 회원/펫, 한도 경계도 유지한다.

Main은 이 헬퍼와 버전 외 전체 소스가 기준 버전과 동일함을 검사한다. Info도 본인 합산 재사용/전달과 해당 헬퍼 외 전체 소스가 동일함을 검사한다. 따라서 명령 가드·권한·화면 문자열·전체 목록 계산/정렬·수동/자동 탐험의 입장/소모·보상·저장 구현은 바뀌지 않았다. 영속 데이터 구조·파일 읽기/쓰기·스킬/매력 공식은 변경하지 않았다.

## 결과 대조와 예외

- 실제 Info 전체 응답에서 `/펫정보`, `/ㅎ`, `ㅁㅁㅁ`, `/종합순위`, `ㅈㅈㅈ`, `/서버순위`의 고유/동점 출력·파일 읽기·무저장 결과를 기준과 비교했다. 출석·정지·레이드·영지·개인톡·복구 대기 및 DEV 응답도 대조했다. 본인 매력 계산 수와 개인 정렬 유지도 실제 함수에 계측했다.
- `node tools/test_ranking_calculation_rhino.js <Rhino 1.7.15 jar> <result.json>`: Main/Info 전체 컴파일, 같은 핵심 6그룹을 실제 Rhino 엔진 정렬로 대조. 실제 Java 파일·1,000명 고유/동점 각 10개 입력(일반·별칭·DEV)의 출력/읽기/무저장 동일과 본인 계산 감소를 확인했다. 전체 Info는 실제 매력 함수를 사용한다.
- 회귀: 명령별 로드 **52**, 회원 표시/검색 인증 **29**, 레이드 펫스킬 **15**, 서버 레이드 **130**, 직전 READY **17**, 펫스킬 보정 **10**그룹 통과. 신규와 합계 **283개 Node 그룹**이다.
- 기존 서버 표시/전체 순위·미니펫 보조/실제 펫정보·모험가 튜토리얼·탐험 수동 정산 안내·Info 영지 제한·홈뱃지 큐브 회귀도 통과했다. 서버 표시 축약 fixture에는 직전 명령별 로드 개선에 따른 파일 경로만 보완했다.

## 개선 전후

로컬 Rhino 1.7.15 인터프리터의 동일 합성 입력, 이전/이후 순서 교대. 헬퍼는 5회 워밍업 후 31회 중앙값이고 전체 Info는 실제 Java 파일과 매력 함수로 3회 워밍업 후 11회 중앙값이다. 원 수치는 `ranking_calculation_benchmark.json`에 보관한다.

헬퍼 시간은 합성 점수 반환 함수를 사용한 순위 판정 구간이며 게임 전체 처리시간이 아니다. 전체 펫정보의 측정 차이는 작고 동점 측정은 증가해 **전체 응답의 일관된 속도 향상은 확인하지 못했다**. PC 부하·GC 영향이 있고 기능 보존을 위해 기존 정렬을 유지했다. 확정적인 개선은 본인 중복 계산 감소와 Main 상위 판정의 정렬 제거다. 운영 Android 기기/외부 메시지 전송 시간은 측정하지 않았다.

검증된 작업 브랜치를 먼저 푸시하고 feature/prod를 반영·푸시한 뒤 원격 커밋·버전·노트를 확인한다. 런타임은 운영자가 main.js와 Info.js를 함께 업로드·컴파일하고 개발자노트 데이터를 적용한다.
