# 펫무쌍 운영 로그 누락 복구

2026-11-07 운영 백업과 `ver_2.782` 수정에 맞춘 운영자용 도구입니다.

1. 봇을 끈 상태에서 `런타임복구.bat`를 실행합니다.
2. `[OK] 데이터 복구 요청 적용 완료`를 확인합니다.
3. 최신 운영 소스로 `tools/03_main_운영반영.bat`를 실행하고 MessengerBot에서 main을 컴파일합니다.
4. `/호이봇버전`이 `ver_2.782`인지 확인합니다.

기존 Git 백업에서 검증한 복구 파일 두 개를 TEMP에 생성합니다. 현재 운영 파일과 복구 사본의 해시가 확인한 백업 또는 기존 저널 재생 상태와 일치할 때만 적용합니다. 회원·재화·무쌍 진행 내용을 유지하면서 로그 참조를 남아 있는 1397번 기록에 맞춥니다. 누락된 1398번 로그 내용은 복원하지 못합니다.

복구 데이터는 Git에 새로 추가하지 않습니다. 생성한 복구 파일과 내려받은 원본은 표시된 TEMP 경로에 보존합니다. 소스 업로드·컴파일·재시작은 이 BAT가 수행하지 않으며, Codex는 운영 기기에 직접 접속하지 않습니다.

ADB 경로 또는 기기를 지정하려면 PowerShell에서 `prepare-runtime-repair.ps1 -AdbExe <경로> -Device <기기>`를 실행합니다. `-PrepareOnly`는 Git 백업으로 복구 파일만 생성하며 ADB를 호출하지 않습니다.
