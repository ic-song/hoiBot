## 승인된 통합 기준

- `ㅁㄱ`는 기존 구매를 유지하면서 BUILD 대기에서만 건설로 연결한다. 앞뒤 공백 외 접미사·대화는 실행하지 않는다. 원래 검증·비용·턴·DEV 분리와 배타 쓰기 잠금을 사용한다. 하루 5회와 이용권 보류 정책은 유지한다.
- 파산 UI는 확정 순위/당사자 → 이동/주인 → 통행료·실지급·부족 → 남은 골드/반환 지역/상금 시점 → 실제 전환·다음 차례 순이다. 0곳 반환은 별도 안내한다. 생존 인원·확정 순위·빈 땅 보드는 같은 상태로 출력한다. 정확히 0골드는 생존하며 종료 조건 충족 시 다음 행동 없이 기존 정산을 진행한다. 진행/게임판 두 메시지와 각각의 allsee는 유지한다.
- 운영 초기화는 `서버관리자`, 소스에 등록된 실제 `testRoom`인 `팻 테스트방`에서 기존 항목별 역할까지 충족해야 처리한다. 다른 방은 읽기·응답·대기 변경·삭제 전에 반환한다. 허용 방 무권한은 권한 안내만 출력한다. 환경/사용자/방/그룹별 세션을 구분하고 최종 권한을 재검사한다. 메뉴 밖 데이터정리·경매초기화·계삭진행·계정잠수삭제·글자수전체정리도 같은 방 제한을 받는다.
- 운영 메뉴에서 개인 `/미니펫전적초기화`를 제외하고 기존 직접 실행·아이템 소모 경로를 유지한다. 개별 댓글/피드 삭제·개인 가방 정리·정기 리셋은 유지한다. `/피드전체삭제`는 기획의 명시 대상이므로 두 운영방과 기존 패스 조건을 적용한다. Info도 동일 운영 명령 목록을 읽기 전에 반환한다.
- 교육방은 교육 전용 판정으로만 허용하며 전역 `isMaster`의 허용 방을 넓히지 않는다. 기존 10챕터 완료·문자 영수증·보상/GM 이력은 유지한다. 총 12개는 챕터당 1개의 합계이며 추가 수료 보상은 없다. 인센티브 300원은 승인된 운영 정산 기준으로, 봇 금전 지급·실적 금액 표시는 추가하지 않는다.
