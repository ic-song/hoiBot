## 구현 범위

- 길드마스터 모집/참가비 설정 → 같은 길드 4명 준비 → 시작 시 소속·잔액 재검증과 참가비 차감. 무작위 순서와 선공 골드 보정, 16칸·10라운드 정순/역순 게임.
- 구매·건설·통행료·이벤트·파산, 생존자 자산순/탈락 역순 정산. 동점 생존자만 한 번 추첨하고 결과 보존. 10% 수수료 제외 후 40/30/20/10% 지급.
- 실제 4명(탈락자 포함) 전원 동의 시 전액 환급. 유효한 진행은 중단 동의를 취소한다. 길드당 KST 하루 3회, 자정에도 현재 경기 유지, 타이머 없음.
- 기존 계정 ID 사용으로 닉변·탈퇴/추방 후에도 진행 가능. 삭제 뒤 같은 닉네임으로 생성된 다른 계정에는 상금을 지급하지 않는다.
- 조회/실패 입력은 무저장, 일반 턴은 소형 경기 파일만 저장. 포인트 변경은 기존 회원 저장과 경기 원문을 복구 기록으로 묶고 다음 명령에서 중단 게시를 먼저 복구한다.
- 기존 채크랭크의 오래된 길드 참조 정리가 경기 조회에서 회원 원본을 바꾸거나 저장하지 않도록 표시용 사본 사용.

## 운영 시작

1. 운영자가 검증된 소스를 MessengerBot에 업로드·컴파일한다.
2. 길드마스터가 `/길드마블` 확인 후 필요하면 `/마블참가비 1`~`10`으로 설정하고 `/마블시작`을 입력한다.
3. 같은 길드의 실제 참가자 4명이 `/마블준비`. 길드마스터가 플레이하려면 본인도 준비한다.
4. 멈춘 게임은 `/마블판`, 규칙은 `/마블가이드`. 정산 대기는 계정/포인트 문제 해결 후 원래 방에서 `/마블굴리기` 또는 `/마블시작`으로 미지급만 재시도한다.

Android MessengerBot의 실제 메시지 표시와 기기 파일시스템은 운영자 확인 영역이다. 모든 자동 검증은 합성 계정과 로컬 임시 파일로 실행했다.
